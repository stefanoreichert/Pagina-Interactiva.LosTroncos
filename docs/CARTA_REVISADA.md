Revisión: 27 de octubre de 2026. Fuente local: [carta.pdf](referencias/carta.pdf), copia del [PDF compartido](https://drive.google.com/file/d/1LXEKSvrkijQsnB9EU_c7h3bThvK8Xyz4/view). Se inspeccionaron visualmente sus ocho páginas renderizadas, no solo el texto extraído.

Esta transcripción registra nombres, importes y condiciones que afectan al diseño. No certifica vigencia comercial. Se conserva `$` como en la fuente; confirmar moneda antes de publicar. Se agregan separadores de miles para legibilidad. Las descripciones completas deberán cotejarse nuevamente al cargar el catálogo; aquí se incluyen las necesarias para resolver variantes y condiciones.
